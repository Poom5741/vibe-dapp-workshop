# Station 0 — Web3 in 10 (0:00–0:10)

Four words carry the whole day. Every helper uses them verbatim.

## The four words

1. **Wallet** — your account on the network. Not email+password: a key pair.
   - Address (`0x…`) = account number → share freely.
   - Seed phrase / private key = your signature → never share, ever. No "forgot password."
2. **Gas** — the tiny fee every *write* costs. Reading is free. Today: transferring, minting, deploying are writes.
3. **Smart contract** — a program stored ON the blockchain. "A vending machine: anyone can use it, nobody can secretly reprice it."
4. **Testnet vs mainnet** — same tech, two worlds. **Fuji** is Avalanche's testnet: free tokens, zero value, perfect rehearsal. Today: Fuji only (chainId **43113**).

## One-minute blockchain

A shared notebook duplicated across thousands of computers. Anyone can add a page
(transaction); everyone's copy updates; nobody can quietly rewrite an old page because the
other copies would disagree. No single admin — that's the whole trick.

## Avalanche in one breath

Fast and cheap (~1s confirmation, fractions of a cent). One main shared chain — the
**C-Chain**, where today's contract goes — plus custom **Avalanche L1s** launched by
companies and games (cheap since the Avalanche9000 upgrade, Dec 2024). **AVAX** pays gas.
